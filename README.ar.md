# 🌐 QuickTranslate — مترجم سريع لديسكورد

> [English README](README.md)

بلجن **BetterDiscord** يسوي شغلتين:

1. **يرسل رسالتك مترجمة:** تكتب بالعربي في مربع الرسالة، تضغط زر 🌐، يترجمها للغة اللي مختارها ويرسلها على طول.
2. **يترجم رسائل الناس:** تمرّر الماوس على أي رسالة، يطلع زر صغير «🌐 ترجم»، تضغطه وتطلع الترجمة تحت الرسالة بلغتك المفضلة.

ما فيه شي يصير من نفسه — كل شي بزر تضغطه.

---

## التركيب

```powershell
powershell -ExecutionPolicy Bypass -File install-quicktranslate.ps1
```

السكربت ينسخ البلجن لمجلد BetterDiscord ويفعّله ويعيد تشغيل ديسكورد. خلاص.

> ملاحظة: يحتاج BetterDiscord مثبّت أصلًا (موجود عندك).

---

## الاستخدام

### 1) ترجمة رسالتي وإرسالها

| الإجراء | النتيجة |
| --- | --- |
| تكتب رسالة + تضغط 🌐 (زر يسار) | يترجمها للغة الإرسال ويُرسلها |
| Shift + ضغط 🌐 | يترجمها ويحطها في المربع **بدون** إرسال (تراجعها أول) |
| ضغط يمين على 🌐 | تفتح قائمة صغيرة تختار منها اللغة |

**مهم:** الإرسال يصير عن طريق ديسكورد نفسها (نفس موديول الإرسال الأصلي)، فما يحصل أي إرسال مكرر أو نص ملخبط.

### 2) ترجمة رسائل الناس

| الإجراء | النتيجة |
| --- | --- |
| تمرّر الماوس على رسالة | يطلع زر «🌐 ترجم» جنب النص |
| تضغط الزر | تطلع الترجمة تحت الرسالة (وضغطة ثانية تخفيها) |
| تضغط «✕ إخفاء» | تخفي الترجمة |

الترجمة تُحفظ بالذاكرة، فلو رجعت للرسالة نفسها تطلع فورًا بدون إنترنت.

## الإعدادات

تلقاها في: **إعدادات BetterDiscord ← Plugins ← QuickTranslate ← ⚙️**

- **لغة إرسال رسائلي** — افتراضي: الإنجليزية.
- **لغة ترجمة رسائل الآخرين** — افتراضي: العربية.
- **أرسل الرسالة تلقائيًا بعد الترجمة** — إذا أطفأتها، الضغط على 🌐 يحط الترجمة في المربع بس.
- **أظهر زر الترجمة عند مرور الماوس** — تشغيل/إيقاف زر الرسائل.

**٩٢ لغة** متوفرة (العربية، الإنجليزية، التركية، الأوردية، الفارسية، الصينية، اليابانية، الكورية… إلخ).

## الإزالة

```powershell
powershell -ExecutionPolicy Bypass -File uninstall-quicktranslate.ps1
```

يشيل ملف البلجن وتفعيله ويرجّع ديسكورد عادي — و BetterDiscord يبقى شغّال.

## كيف يشتغل (تقنيًا)

- **الترجمة:** خدمة `translate.googleapis.com` المجانية (بدون مفتاح API)، عبر `BdApi.Net.fetch` عشان نتجاوز قيود CORS. النصوص الطويلة تُقسَّم لدفعات ≤ 1200 حرف.
- **كشف اللغة:** تلقائي (auto → اللغة الهدف).
- **الإرسال:** `MessageActions.sendMessage(channelId, {content}, undefined, {})`.
- **مربع الكتابة:** يُقرأ ويُعدَّل عبر **محرر Slate** نفسه (`Transforms`/`insertText`/`deleteFragment`) عن طريق شجرة React، وليس بالتعديل المباشر على DOM. السبب: أي تعديل مباشر (execCommand أو تغيير التحديد) يخرب الحالة الداخلية للمحرر فيتوقف الحذف (Backspace) — صارت هذي المشكلة فعلًا وأُصلحت.
- **زر الرسالة:** عنصر صغير يُضاف داخل محتوى الرسالة، ويظهر بـ CSS عند `:hover` (بدون أي تعديل على React).
- **اللغات اليمينية** (عربي/عبري/فارسي/أوردو…) تاخذ `dir="rtl"` تلقائيًا.
- ما يستخدم أي مكتبة خارجية، وما فيه تعديل على حسابك ولا شيء يخص النيترو.

> إذا علّق مربع الكتابة من نسخة قديمة وصار ما يقبل الحذف: اضغط زر 🌐 مرة وحدة — العملية الجديدة على Slate تصلّح الحالة وترجّع الحذف طبيعي.

## حدود الاستخدام

- يحتاج إنترنت (خدمة ترجمة مجانية عامة — استخدام شخصي خفيف).
- ما يترجم الرسائل القديمة تلقائيًا؛ كل رسالة بضغطة.

## الخصوصية والتحذيرات

- الترجمة تجي من نقطة نهاية جوجل **غير الرسمية** `translate.googleapis.com/translate_a/single?client=gtx` (بدون مفتاح، بدون تكلفة). مو API موثّق — ممكن يحدّ الاستخدام أو يتغيّر بدون سابق إنذار.
- **النص اللي تترجمه يُرسل لجوجل** ضمن الطلب. هذا الشي الوحيد اللي يطلع من جهازك: ما فيه تحليلات، ولا تتبع، ولا وصول لحسابك.
- النصوص الطويلة تُقسَّم لأجزاء ≤ 1200 حرف وتُجمع بعدها.
- BetterDiscord تعديل على العميل — استخدمه على مسؤوليتك (سياسة ديسكورد). البلجن ما يستخدم إلا واجهات ديسكورد الداخلية، وبس على شي أنت ضغطته.
